# Fonts

Add custom font files here, including icon fonts.

## Dynamic Font Faces

Regular text fonts in this folder are loaded through [layouts/partials/base/font-faces.html](../../layouts/partials/base/font-faces.html).

That partial is injected at the top of [layouts/_default/baseof.html](../../layouts/_default/baseof.html).

### Rules

1. Put regular text fonts directly in `static/fonts`.
2. Add each font you want to load to `params.includedFonts` in `hugo.toml`.
3. Each `includedFonts` entry must define `name` and `family`.
4. `weight` defaults to `400` if omitted.
5. `style` defaults to `normal` if omitted.
6. The font format is derived from the file extension in `name`.
7. `font-display` is always set to `swap`.
8. Icon font CSS is not generated by this partial and still needs to be handled manually.

### Configuration Example

```toml
[[params.includedFonts]]
	name = "AudiType-Bold.woff2"
	family = "AudiType"
	weight = "700"
	style = "normal"

[[params.includedFonts]]
	name = "AudiType-Normal.woff2"
	family = "AudiType"
	weight = "400"
	style = "normal"
```

### Examples

- `name = "AudiType-Bold.woff2"` with `family = "AudiType"` -> `font-family: 'AudiType'; font-weight: 700; font-style: normal;`
- `name = "AudiType-Normal.woff2"` with no explicit `style` override -> `font-style: normal;`
- `name = "CustomFont-Regular.otf"` -> `src: url('/fonts/CustomFont-Regular.otf') format('otf');`

### When To Edit The Partial

Update [layouts/partials/base/font-faces.html](../../layouts/partials/base/font-faces.html) only if you need to:

1. change the generated `@font-face` properties,
2. add custom validation or filtering for configured fonts,
3. change how the font format is derived from the file name.

## Icon Fonts

Follow these steps to generate an icon font.

1. visit https://icomoon.io/app/
2. Import icons (.svg files)
3. Select the desired icons and click Generate font
4. rename icons if you want and click Download
5. open the zip and copy the contents of `fonts` folder here
6. copy the `style.css` contents to `assets/styles/_icomoon.scss`. Make sure it is included in `style.scss`
