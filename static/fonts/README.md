# Fonts

Add custom font files here, including icon fonts.

## Dynamic Font Faces

Regular text fonts in this folder are loaded automatically through [layouts/partials/base/font-faces.html](../../layouts/partials/base/font-faces.html).

That partial is injected at the top of [layouts/_default/baseof.html](../../layouts/_default/baseof.html).

### Rules

1. Only `.woff2` files are converted into `@font-face` rules.
2. Put regular text fonts directly in `static/fonts`.
3. Use file names in this format: `FamilyName-Weight.woff2` or `FamilyName-WeightItalic.woff2`.
4. Family names are derived from the file name automatically by splitting PascalCase or camelCase into words.
5. `font-display` is always set to `swap`.
6. Icon font CSS is not generated by this partial and still needs to be handled manually. Make sure that it's not picked up by dynamic font faces (shouldn't be .woff2) 

### Supported Weight Tokens

- `Thin` -> `100`
- `ExtraLight` -> `200`
- `Light` -> `300`
- `Regular` -> `400`
- `Medium` -> `500`
- `SemiBold` -> `600`
- `Bold` -> `700`
- `ExtraBold` -> `800`
- `Black` -> `900`

If no known weight token is found, the generated rule falls back to `400`.

### Examples

- `TyponineSansPro-Regular.woff2` -> `font-family: 'Typonine Sans Pro'; font-weight: 400; font-style: normal;`
- `TyponineSansPro-Bold.woff2` -> `font-family: 'Typonine Sans Pro'; font-weight: 700; font-style: normal;`
- `TyponineSansPro-RegularItalic.woff2` -> `font-family: 'Typonine Sans Pro'; font-weight: 400; font-style: italic;`

### When To Edit The Partial

Update [layouts/partials/base/font-faces.css](../../layouts/partials/base/font-faces.css) only if you need to:

1. support additional weight tokens,
2. support a different naming convention,
3. exclude specific files from automatic loading.

## Icon Fonts

Follow these steps to generate an icon font.

1. visit https://icomoon.io/app/
2. Import icons (.svg files)
3. Select the desired icons and click Generate font
4. rename icons if you want and click Download
5. open the zip and copy the contents of `fonts` folder here
6. copy the `style.css` contents to `assets/styles/_icomoon.scss`. Make sure it is included in `style.scss`
